# EportfolioKing

**Professional developer portfolio showcasing modern web development skills and projects**

A sleek, responsive portfolio website built with React and Vite to showcase my development journey, technical skills, and project portfolio. Designed to provide a comprehensive view of my capabilities as a front-end developer.

## 🚀 [Live Portfolio](https://eportfolio-king.vercel.app/)

![Live Demo](https://img.shields.io/badge/Status-Live%20Portfolio-success?style=flat&logo=vercel)

## ✨ Portfolio Sections

**💼 Projects Showcase**  
Curated collection of my best development work with live demos, source code, and detailed project breakdowns.

**🛠️ Technical Skills**  
Comprehensive overview of my programming languages, frameworks, tools, and technologies.

**📋 Professional Resume**  
Downloadable resume with my experience, education, and professional background.

**⚡ Tech Stack Display**  
Visual representation of my current technology stack and development expertise.

## 🎯 Features

- **Responsive Design** - Optimized for desktop, tablet, and mobile viewing
- **Modern UI/UX** - Clean, professional design that highlights content
- **Fast Performance** - Built with Vite for optimal loading speeds
- **Project Integration** - Direct links to live demos and source code
- **Professional Branding** - Cohesive design that reflects my development style

## 🛠️ Built With

- **Frontend:** React 18, JavaScript (ES6+)
- **Build Tool:** Vite with Hot Module Replacement
- **Styling:** Modern CSS3 with responsive design
- **Deployment:** Vercel with automatic deployments
- **Performance:** Optimized bundle size and loading times

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/mikebikeking/EportfolioKing

# Navigate to project directory
cd EportfolioKing

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:3000` to view the portfolio locally.
